------------------------------------------------------------------------
BACKEND (Laravel + MySQL) - current state
------------------------------------------------------------------------
- Models: User, Supplier, Product, StockMovement, SafetyStock, SalesHistory.
- Migrations: users, cache, jobs, suppliers, products, stock_movements,
  safety_stock, sales_history. Seeders: InventorySeeder, DatabaseSeeder.
- API routes (routes/api.php), all currently UNAUTHENTICATED (Sanctum auth
  is a planned later phase):
    * GET/POST/PUT/PATCH/DELETE  /api/products (+ /{code})
    * apiResource               /api/suppliers
    * GET/POST                  /api/stock-movements
    * GET/POST/DELETE           /api/sales-history (GET accepts ?product=)
- ProductController returns the frontend JSON shape (id = product code) and
  joins safetyStock (safety_stock + annual_demand) so the Auto Calculator
  can auto-fill demand.
- StockMovementController records Stock In/Out inside a DB transaction with
  a row lock (lockForUpdate) and recomputes products.stock_on_hand in the
  same transaction so the balance can never drift.

FRONTEND WIRING STATUS
- Wired to the API:  Product & Supplier, Stock Control.
- NOT yet wired:     Forecasting (still uses sample history),
                     Auto Calculator (receives handoff prop, no fetch yet).
